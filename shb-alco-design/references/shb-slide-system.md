# SHB Slide System · v1

## Objective

Preserve institutional consistency while improving executive readability. This reference is intentionally conservative: SHB/ALCO decks should feel coherent, disciplined, and decision-oriented rather than experimental.

## Default layout behavior

- 16:9 widescreen unless the source deck uses another format.
- Use the existing title band, logo position, footer, and page numbering from the source deck when available.
- Build on a clear grid. Align charts, tables, and callouts to consistent column edges.
- Favor 1 primary visual + 1 supporting block over many equally weighted cards.
- Maintain generous whitespace around the main message.

## Typography

- Preserve fonts from the source deck if supplied.
- Use a restrained hierarchy: title, executive message, section label, body/data label, footnote.
- Avoid shrinking text to fit. Reduce content density before reducing legibility.
- Numbers that drive the conclusion should be visually stronger than descriptive text.

## Color behavior

- Preserve SHB brand colors and existing deck palette.
- Use accent colors semantically, not decoratively.
- One highlight color should usually represent one meaning across a slide.
- Use neutral tones for context and historical/comparison data.
- Avoid rainbow category palettes unless categories cannot be read otherwise.

## Tables

- Use tables when precision matters.
- Keep row/column separators light and sparse.
- Highlight only decision-relevant cells.
- Prefer variance columns and directional indicators over decorative heatmaps when the audience needs exact numbers.
- Keep units in headers, not repeated in every cell where possible.

## Charts

- Start axis at zero for magnitude comparisons unless there is a justified analytical reason not to.
- Show direct labels where they reduce legend hunting.
- Avoid redundant data labels.
- Use plan/target/reference lines with clear labels.
- Use callouts only for inflection points or management-relevant gaps.

## Executive headline

Prefer an insight-led headline over a topic label.

Weak: `Tình hình huy động vốn`

Better: `Huy động tăng chậm hơn tín dụng, duy trì áp lực bổ sung nguồn TT1 trong Q4`

The headline must be supported by the visual and should not overstate causality.

## Existing deck adaptation

When a source ALCO deck is available:

1. inspect 3–5 representative slides;
2. identify title rhythm, card radius, border weight, chart style, table style, font scale, and footer treatment;
3. reuse those motifs before introducing new ones;
4. change the design language only when the user explicitly asks for a redesign.

## Density

For management slides, target one main conclusion per slide. If the slide requires more than three competing conclusions, consider splitting it.

## Footnotes and sources

- Keep definitions and caveats concise.
- Distinguish source note from analytical note.
- Add timing basis when needed: `Tại 31/08/2026`, `8T/2026`, `YTD`, `bình quân tháng`, etc.
- For estimates, label clearly as estimate/ước tính.
