# Visual Language · v2

## Objective
Create professional management visuals that are clear, disciplined, and adaptable.

## Typography
- Preserve source fonts when available.
- Use a restrained hierarchy: title, executive message, section label, body/data label, footnote.
- Numbers that drive the conclusion should be visually stronger than descriptive text.
- Reduce content before reducing legibility.

## Spacing and alignment
- Use clear grids and shared alignment edges.
- Keep consistent internal padding within repeated components.
- Use whitespace to separate semantic groups.

## Composition
- Prefer one primary visual plus supporting evidence over many equally weighted cards.
- Use asymmetry when it improves hierarchy; symmetry is not mandatory.
- Do not force every page into a dashboard layout.

## Color
- Use SHB brand colors as anchors.
- Use accent colors semantically.
- Use neutral tones for historical/comparison/context data.
- Avoid rainbow palettes unless categories genuinely require them.

## Components
Cards, bands, icons, separators, and labels are optional tools. Use them only when they improve grouping, scanning, or emphasis.

## Existing documents
When revising an existing deck/report, preserve the visual grammar unless the user explicitly asks for a redesign.
