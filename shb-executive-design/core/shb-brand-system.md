# SHB Brand System · v2

## Role
Preserve recognisable SHB institutional identity without forcing every deliverable into one rigid template.

## Brand behavior
- Reuse official SHB logo assets supplied by the user or source document.
- Preserve existing brand colors from the source deck/report when available.
- Use SHB orange and blue as identity anchors, not as decorative fill everywhere.
- Neutral greys and white should carry most structural/background work.
- Accent colors must have meaning and remain consistent within a deliverable.

## Layout identity
Recognisable SHB DNA should come from:
- disciplined title treatment;
- consistent logo placement;
- restrained blue/orange accents;
- clean spacing and alignment;
- executive typography hierarchy;
- structured financial tables and charts;
- concise source/footer treatment.

## Flexibility
Do not require identical card shapes, section bands, dashboard grids, or page compositions across all deliverables.

## Source-document precedence
If an existing SHB document is supplied, treat its established brand grammar as the primary reference unless the user asks for a redesign.

## Asset discipline
Never invent a new SHB logo, tagline, proprietary font, or brand asset. Use supplied/verified assets only.
