# Pattern · Funding Flow

Use when the communication problem is about funding sources, uses, liquidity transmission, or TT1/TT2 interaction.

## Typical structure
1. External sources
2. Domestic sources
3. Banking-system transmission layer with TT1 / TT2 separated
4. Uses of funds
5. Pressure indicators

## Quantification discipline
- Arrow thickness may represent size only when quantities are measured on a comparable basis.
- If not comparable, use equal-width conceptual arrows and place numeric indicators beside nodes.
- Label stock, flow, YTD growth, and qualitative signals explicitly.
- Do not imply an accounting identity or causal transmission that the data cannot prove.

## Preferred forms
- economy-to-banking map;
- TT1 vs TT2 pressure bridge;
- flow map + time-series strip.

## Avoid
- decorative Sankey styling with fake magnitude;
- treating FDI/remittance flows as equivalent to banking deposits;
- using an unverified funding gap as the central truth;
- mixing stocks and flows without labels.
