# Pattern · Strategic Balance Sheet Dashboard

Use when management needs to assess progress toward balance-sheet targets.

## Core principle
This is a progress-to-plan view, not a balance-sheet dump.

## Typical indicators
- Total assets
- Customer loans
- Customer deposits
- Accrued interest / interest receivables when relevant
- Deposits and borrowings from other credit institutions
- Equity / capital

## Preferred metrics
- actual level vs target;
- actual growth vs required growth;
- remaining amount / remaining growth;
- recent run-rate vs required run-rate;
- management status when supported by explicit thresholds or judgement.

## Preferred forms
- horizontal progress bars for 5–10 indicators;
- progress rings for only a few headline metrics;
- required-run-rate dashboard when year-end feasibility is the main question.

## Avoid
- repeating detailed balances already shown elsewhere;
- ring/donut overload;
- inconsistent target denominators;
- treating higher values as automatically better;
- traffic-light statuses without an auditable basis.
