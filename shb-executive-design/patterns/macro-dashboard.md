# Pattern · Macro & Market Dashboard

Use this only when the task is a broad macro/market management overview. It is an accelerator, not a mandatory template.

## Typical structure
- Growth / inflation
- Money / credit / liquidity
- FX / external
- Global policy / markets

## Good use
A compact executive overview where each important indicator shows:
- latest value;
- explicit comparison basis (YoY/YTD/MoM/etc.);
- trend or regime;
- one concise interpretation.

## Preferred forms
- macro pulse matrix;
- four-quadrant dashboard;
- headline + 3–4 key charts when inflections are central.

## Rules
- Data values and comparison periods should be explicit.
- Tables are preferred when many indicators coexist.
- Charts are reserved for trends, divergences, or inflections.
- Avoid news-ticker aesthetics and generic qualitative labels.
- Do not create a standalone implication box when the narrative can integrate implications directly.
